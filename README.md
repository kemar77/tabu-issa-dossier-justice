## Précaution d'usage

Ce dossier est préparé **à destination d'un avocat**. Chaque affirmation porte sa pièce (page) ou son statut
(ÉTABLI / ALLÉGUÉ / NON ÉTABLI / TEXTE LU / À VÉRIFIER). Les transcriptions OCR comportent des zones
illisibles marquées comme telles — les manuscrits (dates, montants, signataires) exigent les originaux ou un
rescan 300 DPI. **Aucune décision juridique ne se prend sur ce dossier seul.**
